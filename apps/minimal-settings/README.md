# Minimal Settings

A fast fullscreen settings frontend for rooted LG webOS TVs. It exposes a deliberately small set of verified controls and links to LG Settings for advanced features.

Settings are read immediately before context-sensitive writes so picture changes stay scoped to the active input and picture mode.

Arrows navigate without changing values. Press OK to enter edit mode, use Left/Right to change a value, and press OK or Back to leave edit mode.

The app currently includes picture mode, panel brightness, black level, contrast, colour temperature, energy saving, sound mode, Quick Start+, live Wi-Fi and Ethernet status, and a Wi-Fi on/off control. Detailed network setup and less common options remain available through LG Settings.
